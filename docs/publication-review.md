# 공개 전 검토 기록

검토일: 2026-11-17. 공개용 사본의 문서·소스·포함 파일에 대한 사전 점검이며 변호사의 법률 의견서나 모든 권리의 보증은 아닙니다.

## 공개 범위와 조치

| 항목 | 확인과 조치 |
|---|---|
| 대학 캐릭터 이미지 | [인천대학교 횃불이 공식 페이지](https://www.inu.ac.kr/inu/731/subview.do)에 다운로드가 있으나 GitHub 재배포·수정·재허락 범위는 확인하지 못함. PNG 3개와 해당 이미지를 포함한 영상·스크린샷·ZIP을 공개 사본에서 제외하고 기본 상태 표시 사용 |
| 내장 폰트 | 기존 UI의 base64 폰트는 이 사본에서 제거. 시스템 폰트 사용. 폰트 원본을 재배포하지 않음 |
| 학습 참고 자료 | 하루 AI 영상·자막·프롬프트 문서를 배포하지 않고 참고 링크만 제공. 초기 개발 기록에 해당 자료를 참고한 사실이 있음. 외부 원문과 소스의 전체 동일성 감정·원저작자 이용허락 확인까지 수행한 것은 아님 |
| 개인정보 | 실제 수업 파일·일정·개인 메모·녹음·운영 로그·캡처·개발 대화·백업·환경 파일을 복사하지 않음. 포함 데이터는 시연용 예시 |
| 자격증명 | 배포 파일의 키·토큰·비밀번호 패턴과 로컬 사용자 경로를 점검. 실제 키 값 대신 환경 변수 이름만 사용 |
| 이력 | 원본 폴더는 Git 저장소가 아니었음. 공개용 사본에 새 이력을 만들며 과거 개발 세션·백업 이력을 반입하지 않음 |
| 표시 | 비공식 프로젝트 고지. 예시 기능과 실제 구현, 검증 범위를 구분. 시연 대사에도 예시·시연 표시 보강 |
| 라이선스 | 공동 권리·학습 참고 자료의 권리 범위를 확정하지 않고 MIT 등 포괄 라이선스를 임의로 부여하지 않음. 코드 공개만으로 별도 오픈소스 라이선스를 부여하는 것은 아님 |

자료가 웹에서 다운로드된다는 사실만으로 재배포 허용을 단정하지 않았습니다. 이용허락 범위 판단은 [저작권법 제46조](https://www.law.go.kr/법령/저작권법/제46조), 개인정보의 제3자 제공은 [개인정보 보호법 제17조](https://www.law.go.kr/법령/개인정보보호법/제17조)를 검토 근거로 삼았습니다. 실제 서비스 운영의 적법성은 수집 데이터·동의·제공자·국외 이전 등 구체적인 운영 형태에 따라 별도 판단해야 합니다.

## 제3자 구성요소

Python 의존성은 `requirements.txt`로 설치하며 패키지 소스·바이너리를 이 저장소에 포함하지 않습니다. MLX 모델 가중치, Claude Code 실행 파일, macOS 음성도 배포하지 않습니다. 각 패키지·모델·서비스는 자체 라이선스와 이용 조건을 따릅니다. 의존성 버전은 기존 파일처럼 고정되지 않았으므로 설치 시점의 전체 전이 의존성 라이선스·취약점 감사까지 완료했다고 주장하지 않습니다.

[Claude Code 법률 안내](https://code.claude.com/docs/en/legal-and-compliance)에 따라 자신의 인증을 사용해야 하며, 구독·인증정보 공유나 과금 대행을 안내하지 않습니다. 호스팅·제품 탑재·상업 제공 시에는 별도 계약 조건을 확인해야 합니다. [GitHub 라이선스 안내](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)상 공개 저장소의 열람·포크와 범용 재사용 라이선스는 구별됩니다.

## 보안상 남는 한계

소스 공개는 실행 서버의 인터넷 공개와 다릅니다. 이 저장소는 로컬 프로토타입이며 인터넷 서비스로 배포하지 않았습니다. `JARVIS_KEY`는 완전한 인증 시스템이 아니고, AppleScript·화면 조작은 강한 격리 없이 작동할 수 있습니다. persona의 승인 문구도 강제 실행 게이트가 아닙니다. 실제 사용자 데이터로 운영하거나 다중 사용자에게 제공하기 전에는 별도 설계·검증이 필요합니다.

## 검증 범위

- Python 소스 문법과 기존 `selftest.py --quick`.
- 공개 UI의 JavaScript 문법·외부 캐릭터/내장 폰트 참조 제거.
- 로컬 시연 서버에 글자 질의를 보내는 HTTP 통합 검사: 브리핑, 교통, 날씨, 학식, 검색, 퀴즈·해설, 관계, 정리, iCloud, 메모, 현재 시각. 답변·카드·음성 없는 응답 확인.
- 무효 공유 키의 접근 거부와 서버 loopback 바인딩 확인.
- 배포 파일 목록·비밀정보 패턴·원본 보존 확인.

실제 사람의 마이크 발화, 폰 실기기, 소음 환경, 스피커 에코, 일반 Claude의 실제 도구 수행, 요금 발생 경로, 장시간 운영은 이번 공개 준비 검증에 포함하지 않았습니다. 기존 영상은 기능 완성이나 실시간 정보 연동의 검증 근거로 사용하지 않습니다.
